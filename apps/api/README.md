# apps/api — Backend principal (NestJS)

**Créé en Phase 1** de la roadmap : Prisma + PostgreSQL 16/PostGIS, auth JWT,
CRUD missions/arrêts, import CSV/XLSX, modules `routing` (client OSRM) et
`geocoding` (Photon puis repli sur la base d'adresses propriétaire),
documentation OpenAPI sur `/docs`.

Les dépendances d'infrastructure sont déjà disponibles depuis la Phase 0 :

```bash
pnpm infra:up
```
