# apps/web — Dashboard flotte (React + Vite)

**Créé en Phase 4** de la roadmap : gestion de flotte, import CSV/XLSX des
courses du jour, écran de correction des adresses non géocodées — chaque
correction alimente la base `Address`, l'actif stratégique du projet —,
optimisation VRP, visualisation des tournées sur MapLibre GL JS, suivi temps
réel et rapport de fin de journée.
